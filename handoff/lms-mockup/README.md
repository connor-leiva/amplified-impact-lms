# The $37 skill buyer inside the LMS: mockup for approval

**Status:** design only, for Connor's approval (Nov 24, 2026). Nothing here is built or live.

## The base mockup

Connor's `lms-mockup.zip` (`index.html`, `ai-motion.css`, the Geist fonts and the academy logo) is already in the repo. It is byte for byte `handoff/lms-v3/mockup/`: `index.html` sha256 `ab62643b…d9d1d`, the approved LMS v3 mockup, revision v7, D-225. So it is not copied a second time. This folder extends it, and leaves every file of it as it is.

- **Shell and components.** The same sidebar, top bar, account trigger, hero, lists, cards, chips, segmented control, breadcrumbs, icons and motion.
- **Stylesheets.** The mockup's two stylesheets, linked as they are: `handoff/lms-v3/src/lms.tokens.css` and `lms.css`, generated from `index.html`. The app already ships these two files byte for byte.
- **What the buyer pages add.** `buyer.css` is built only from the mockup's own tokens (`--sp-*`) and classes, with no new colour, font, radius or motion value. `buyer.dark.css` adds the dark theme (see "Dark" below).
- **Data.** `buyer-data.js` is generated by `tools/make-data.ts` from the real catalog, the library's lead copy and the guided setups. Every skill title, line and setup step on these pages is the product's own.

## Open it

```bash
npx http-server . -p 4455
```

Run that from the repo root, then open <http://127.0.0.1:4455/handoff/lms-mockup/buyer.html>. The black MOCKUP bar switches:
- **Bought:** an owner skill, an agent skill, or two skills.
- **Theme:** Light or Dark.
- **Page:** one of the six pages below.

To capture the screenshots, run `node handoff/lms-mockup/tools/capture.mjs --out <dir> [--b64]` (1280 and 390, light and dark).

## How it answers Connor's three problems

1. **The upgrade CTA isn't compelling.** There is one path, shown with what it gets them:
   - **The upgrade card.** It names the plan, shows its price large with its minimum, and lists what it opens: every skill, weekly office hours, and new skills and updates. It also says "Team P&L Review stays yours".
   - **Real previews.** The locked areas show what is inside, with real titles, steps and lines, so the buyer sees what they're missing before the button asks.
   - **Which plan.**
     - It follows the skill's set, as the library does today (`skillUpsell`): agent skills open Agent Insiders, $79/Month; owner, ops and both open Team Leader Insiders, $169/Month.
     - Weekly training is the one exception: Upgrade to the Agent Plan, $117/Month.
     - Every monthly plan says 3-Month Minimum.
   - **$37 for one skill.** "Get This Skill, $37" stays on every locked skill, as the second choice. The library also says "Any one of them is also $37 on its own."
2. **The skill they bought should be up top.** It is the Home hero, the first section of the Skill Library, and the top bar's strip on every other page.
3. **It's disconnected from the LMS.** They are inside it: the same shell, sidebar, top bar, account menu, theme and type as members, with the rest of the LMS visible and locked.

## Rules

- **Utah Life.** Nothing changes. An access-group member never sees these pages; their `/skill-library` stays as it is, with no upsell or buy button.
- **Agent Plan, Team Plan, Insiders and Accelerator members.** No change.
- **Who sees these pages.** Only a learner with at least one $37 skill, no plan and no access group.
- **Copy.**
  - Headings and buttons are Title Case. There are no em dashes. Times say MT.
  - **Numbers.** Every number is computed from the catalog (48 locked, 33 for Agent Insiders) or quoted from the pricing page ("7 AI employees built with you", "8 live builds, 90 minutes, Wednesdays", "With at least 5 running by Feb 3").
  - **Hires.** The hires list ends "Every hire reads and drafts. Nothing is sent without you."
- **Claude and ChatGPT.** Their buttons and setup tabs are the same component, side by side. No page here shows a prompt.
- **Links.** No link is in code. Each upgrade button names its cart (`data-cart`), and in the build its href is that cart's `PAYMENT_LINK_*` from `GET /api/offer`:

  | Cart | Variable |
  |---|---|
  | `insiders-monthly` | `PAYMENT_LINK_INSIDERS_MONTHLY` |
  | `insiders-agent-monthly` | `PAYMENT_LINK_INSIDERS_AGENT_MONTHLY` |
  | `agent-monthly` | `PAYMENT_LINK_AGENT_MONTHLY` |

  "Get This Skill, $37" is today's in-app checkout.
- **Accessibility.** axe finds no serious or critical issue on any of the six pages, at 1280 and 390, in light and dark.

## Dark

The LMS v3 mockup draws light only (D-226). These pages follow the step page's dark pass exactly (`step-page.dark.css`, D-210 with D-185):
- Every mockup colour token is redefined from `tokens.css`'s dark values when the person's Theme is Dark, so there is no raw colour.
- The logo becomes the brand's reversed file.
- It is scoped to the buyer's frame (`data-buyer`), so no member page changes.
