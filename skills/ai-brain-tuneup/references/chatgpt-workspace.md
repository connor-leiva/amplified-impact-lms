# ChatGPT Workspace: What It Holds and How to Copy Each Piece

Last verified: 2026-11-10. OpenAI's help center (help.openai.com) blocks direct reading by our tools, so its facts below come from its articles as they appear in search results on 2026-11-10, and the Project click path from Amplified's vendor check of 2026-11-08 (the same steps the house setup uses). OpenAI's own ChatGPT docs (learn.chatgpt.com) were read directly. Each line says which. ChatGPT's menus and limits change often: follow the screen when it differs, and say so in Flags.

## The Pieces

| Piece | What it reaches | Where it lives |
|---|---|---|
| Project instructions | Every chat in that project | The project's more options menu (•••) > Project settings |
| Project files | Every chat in that project | The project's Sources tab |
| Memory | Chats that reference it; a project can keep its own | Settings > Personalization > Manage memories |
| Custom instructions | Every chat on the account | Settings > Personalization |

## Projects

- A ChatGPT project keeps related chats, files, instructions and sources together. Each project has a Chats section and a Sources section for uploaded files and connected context, and "Project instructions apply across its chats." (learn.chatgpt.com/docs/projects, read 2026-11-10: https://learn.chatgpt.com/docs/projects)
- Project instructions: the project's more options menu (•••) > Project settings > Instructions, then Save. (Amplified's vendor check, 2026-11-08.) They "apply only within that project and override your global custom instructions." (Projects in ChatGPT, https://help.openai.com/en/articles/10169521-projects-in-chatgpt, via search 2026-11-10)
- Files go on the project's Sources tab. Free ChatGPT holds 5 files in a project. (Amplified's vendor check, 2026-11-08.) Limits on other plans differ between sources and are not stated here.
- Project memory: a project uses default memory or project-only memory, set in Project settings, and a shared project is set to project-only memory. (Projects in ChatGPT, via search 2026-11-10)
- **To copy them for a tune-up:** open Project settings, select all the text in Instructions and copy it. For files, attach the originals from your computer; no download path for project files was checked.

## Custom Instructions

- Settings > Personalization holds custom instructions and the "about you" fields (what ChatGPT should call you, what you do, and more about you). Labels vary by app and version. (Custom instructions for ChatGPT, https://help.openai.com/en/articles/8096356, via search 2026-11-10) OpenAI's docs say: "Open Settings to update your personal instructions, memories, and other available personalization controls." (learn.chatgpt.com/codex/personalize, read 2026-11-10: https://learn.chatgpt.com/codex/personalize)
- Settings > Personalization > Base style and tone sets "how ChatGPT responds." It is ChatGPT's closest piece to a custom style, and it can fight a tone line in a project's instructions. (learn.chatgpt.com/codex/personalize)
- Length: the smallest custom instructions limit reported is 1,500 characters (Free and Go, via search 2026-11-10), and the voice profile's QUICK CARD is written to fit it. Keep a custom instructions rewrite under 1,500 characters.
- **To copy them:** open Settings > Personalization, select all the text in each box, copy.

## Memory

- Two switches: "Reference saved memories" and "Reference chat history." (Memory FAQ, https://help.openai.com/en/articles/8590148, via search 2026-11-10)
- **To view and delete:** Settings > Personalization > Manage memories, or tell ChatGPT to forget something. Deleting a chat does not delete the saved memories made from it; to remove something fully, delete the saved memory and the chat where you shared it. (Memory FAQ and How does reference saved memories work, https://help.openai.com/en/articles/11146739, via search 2026-11-10)
- A Temporary Chat doesn't use or create memories. (How does memory use past conversations, https://help.openai.com/en/articles/10303002, via search 2026-11-10)
- **To copy it for a tune-up:** open Manage memories and copy the list. Or, in a chat (inside the project, if it keeps project-only memory), ask: "List every memory you have saved about me, word for word, one per line, with the date saved if you have it. Don't summarize, group or leave any out." Copy the answer into a .txt file.

## Data Export

- Settings > Data controls > Export data, then confirm. The download link comes by email, can take up to 7 days, and expires 24 hours after you get it. Self-serve export isn't offered on Business or Enterprise workspaces. (How do I export my ChatGPT history and data, https://help.openai.com/en/articles/7260999, via search 2026-11-10) The export holds every chat, so don't attach it whole to a tune-up.

## Running the Tune-Up in ChatGPT

- Run it in its own project (the AI Brain Tune-Up project), not inside the project being tuned: that project's instructions apply to every chat in it, so they would steer the audit.
- Paste the rewrite back where each piece came from: Project settings for project instructions, Settings > Personalization for custom instructions, Manage memories for memory.
