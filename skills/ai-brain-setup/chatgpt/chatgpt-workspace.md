Last verified: 2026-11-10. Each source is listed at the end with what it says. Menus change. If a click path here doesn't match what the user sees, trust the screen, say so, and point to OpenAI's help article.

## Facts That Shape the Setup

**Custom Instructions**
- The voice profile guide (amplifiedimpact.io/voice-profile) tells ChatGPT users to paste the QUICK CARD into Custom instructions, and says they "hold about 1,500 characters, and the QUICK CARD is written to fit."
- So: with a QUICK CARD already there, Custom Instructions keep the QUICK CARD, and How I Like to Work goes at the top of the project's instructions. With no QUICK CARD, How I Like to Work (with its default voice line) goes in Custom Instructions.
- Third-party guides disagree on today's limit (some say 1,500 characters on Free and Go and more on paid plans). Staying under about 1,500 fits every account.

**Projects**
- Projects are on Free, Go, Plus and Pro. Free allows 5 files per project.
- Project instructions "only apply inside the respective project and will override your global custom instructions." A chat moved into a project picks up its instructions and files.
- Use a Project, never a custom GPT: OpenAI retires custom GPTs on December 11, 2026.
- PDFs added as project files are read as text only, so About My Business goes in as a plain text file named About My Business.txt.

**Project memory**
- Each project can use default memory or project-only memory, set under Memory in the project's settings. In a project-only project, chats don't have access to ChatGPT's memory, and turning project-only on removes that project's information from memory used outside it. Shared projects are locked to project-only.
- So: leave the AI Brain project on default memory, so the Facts to Remember reach it.

**Memory**
- Controls depend on the memory experience: they may include Memory, Reference saved memories, Reference chat history, Memory summary, Manage, or Saved memories.
- Saved memories are kept apart from chat history: deleting a chat does not delete a saved memory. Delete it in the Memory settings, or ask ChatGPT to forget it.
- Turning off Reference saved memories also turns off Reference chat history.
- Free users have a lighter version of memory than Plus and Pro (OpenAI's 2025 announcement, from search excerpts). Business and Enterprise workspace controls were not checked.
- So: say the Facts to Remember in a new chat outside any project, then check Settings, Personalization, Memory. After a password or client detail lands in a chat, deleting the chat isn't enough: check the saved memories too.
