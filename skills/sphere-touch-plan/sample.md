## Set It Up in Follow Up Boss

These are steps for you, your Account Owner or an admin. This skill doesn't change anything in Follow Up Boss.

1. **Text Consent (you have it).** Keep filling it only from written records, with the date and source. Change "Yes - verbal at closing" (Milo) once you have a written yes, or clear it. A verbal yes still contains "Yes," so it would slip into the Text OK list below.
2. **Smart Lists** (People > All People > Filters, add the filters, + New List, name it, Save List):
   - **Past Clients: Due:** Tags include Past Client; Last Communication was more than 30 days ago. Your account's default Past Clients list (Stage includes Closed, Last Communication more than 90 days ago) overlaps; yours uses the Past Client tag, so keep whichever you'll actually open.
   - **Close Sphere: Due:** Tags include Sphere A; Last Communication was more than 60 days ago.
   - **Wider Sphere: Due:** Tags include Sphere B; Last Communication was more than 90 days ago. Tag Pip first.
   - **Text OK:** Text Consent contains Yes; Tags exclude Do Not Text and Do Not Call.
3. **Home anniversaries.** You already have a Home Anniversary field (only Ben's is filled). Ask your Account Owner to check it's a Date field with Occurs Every Year (Admin > Custom Fields), then fill it for your other past clients from their Deal Close Date; every date is in Check Before Sending and the export. An admin then makes an action plan whose first step is a task, "Home anniversary: send a personal note," and an automation (Admin > Automations): the Calendar Date trigger, Home Anniversary, "is in 0 days," start that action plan, and "Run automation multiple times per person" so it repeats every year. It starts at 8 AM in your company time zone. An action plan started by an automation doesn't send its first text, so the task reminds you and you send by hand.
4. **One action plan per tier**, made of tasks (call, personal check-in, handwritten note, home value review) about 30 days apart, matching the months above. Action plans can't be applied in bulk: start one on each contact, or ask your admin about an automation.
